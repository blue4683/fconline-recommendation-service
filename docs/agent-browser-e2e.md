2026-10-21 / Stage4-B·4-C 데모 경로. 사용자 승인 범위에서 Vue 실제 연결 → HTTP/SSE → qwen3:8b → 정규화 → 합성 스냅샷 → CP-SAT·독립 검증 → 웹 표시를 확인했다. 백엔드는 develop `00623baa3fee6d0c2c5b3944500d917370fd63d2`(PR#79), 웹은 PR#75/#78을 포함한다. [HTTP 앱](synthetic-agent-api.md)과 기존 web-agent.v0를 사용했고 제품 코드·웹/WEB-*는 변경하지 않았다.

## 승인과 실행 이력

- 최초 승인 `agent-web-e2e-20261021-001`: 명시 합성 배치/관측 시각·Agent/Vite 임시 실행·상태 최대2회+추론 최대3회·정상/누락/충돌·순차·재시도/다운로드/외부 전송 없음·오류 즉시 중단·기록 보존·시작한 서버 종료. Node22/기존 lock의 npm ci·타입/테스트/빌드도 승인받았다.
- 001은 첫 /api/version 요청의 연결 거부(ConnectError)로 stopped_preflight, 상태1회·추론0회·브라우저 요청0회다. Agent를 종료했고 Vite/브라우저는 시작하지 않았다. 종료 실행과 남은 상한은 재사용하지 않는다.
- 외부 요청 전 실행기 준비 중 Python 경로의 symlink를 해석해 가상환경을 벗어난 import 실패도 있었다. 메타데이터/추론/승인 잠금 생성 전이며 네트워크0회다. 가상환경 실행 파일 경로를 유지하도록 실행 명령만 고쳤고 로그를 보존했다. 제품 코드 수정/환경 재설치는 하지 않았다.
- 사용자가 설치된 Ollama 시작과 동일 조건의 새 1회 `agent-web-e2e-20261021-002`를 별도로 승인했다. Ollama를 loopback11434·cloud/prune 비활성·순차로 시작했다. /api/version·/api/tags2회로 명시 모델 digest를 확인한 뒤, Agent8001/Vite5173을 loopback에서 실행했다.
- 002는 상태2회·추론3회·브라우저 POST3회로 완료했다. 재시도/모델 다운로드/넥슨/외부 tracing·원문 전송은0회다. npm ci는 고정 패키지 설치이며 모델/원문 전송과 구분한다. 기존 001·이전 ASGI 승인 기록은 보존했다.

두 실행 모두 상한 예약을 요청 전에 로컬 manifest에 저장한다. 진단 wrapper는 정확한3개 원문/순서/요청 수를 검사하고 다른 요청을 거부하며 실제 앱·selector/엔진을 그대로 감싼다. 일반 데모 서버의 인증/운영 제한을 구현한 것으로 간주하지 않는다.
