- agent의 공동저자·생성 도구 표기를 커밋·PR·최종 squash 메시지에 넣지 않는다. Git의 기존 사람 신원을 바꾸지 않는다.

## Stage 1-D 소량 기술 확인 — 중단 상태

수집 예외를 재사용하지 않고, 기존 단건·소량 구조 확인 범위에서만 확인했다. 임시 검사 스크립트에 최대 10회·최소 1초 간격·재시도 없음·이상 응답 즉시 중단을 적용했고 **6회에서 중단**했다. 이 스크립트를 초기화해 계속 요청하지 않는다.

- 로컬 근거: `data/raw/stage-1-d-inspection-20261018/manifest.json` 및 `.body` 파일. 상태 stopped, attempts=6.
- 1: POST PlayerPriceGraph, spid=100000250, n1strong=5 → 200.
- 2: 같은 카드 11강 → 200.
- 3: GET `/datacenter/teamcolor` → 200, 공식 목록 HTML.
- 4: 공식 페이지가 참조한 datacenter.teamcolor.js → 200.
- 5: 공식 페이지가 참조한 datacenter.js → 200.
