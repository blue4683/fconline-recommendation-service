## 개발 운영 결정

- agent의 공동저자·생성 도구 표기를 커밋·PR·최종 squash 메시지에 넣지 않는다. Git의 기존 사람 신원을 바꾸지 않는다.
- 최신 develop에서 type/설명 브랜치 생성. codex/ 접두사 금지.
- 영어 Conventional Commits와 PR 제목. 문서·코드 주석은 한국어.

## Stage 1-D 소량 기술 확인 — 중단 상태

수집 예외를 재사용하지 않고, 기존 단건·소량 구조 확인 범위에서만 확인했다. 임시 검사 스크립트에 최대 10회·최소 1초 간격·재시도 없음·이상 응답 즉시 중단을 적용했고 **6회에서 중단**했다. 이 스크립트를 초기화해 계속 요청하지 않는다.

- 로컬 근거: `data/raw/stage-1-d-inspection-20261018/manifest.json` 및 `.body` 파일. 상태 stopped, attempts=6.
- 1: POST PlayerPriceGraph, spid=100000250, n1strong=5 → 200.
- 2: 같은 카드 11강 → 200.
- 3: GET `/datacenter/teamcolor` → 200, 공식 목록 HTML.
- 4: 공식 페이지가 참조한 datacenter.teamcolor.js → 200.
- 5: 공식 페이지가 참조한 datacenter.js → 200.
- 6: 공식 JS의 GET `/datacenter/TeamColorDetail?teamcolorid=1001` → **302**, 본문 링크가 `http://bulletin.nexon.com/nxk/error.html?aspxerrorpath=/datacenter/TeamColorDetail` 오류 페이지를 가리킴.
- 오류 페이지를 따라가거나 같은 호출을 재시도하지 않았다. 첼시/뮌헨 상세 호출은 로컬 중단 가드가 거부했으므로 실제 HTTP 요청하지 않았다.
- 원인은 미확정이다. 이를 로그인 요구나 차단 403/429로 단정하지 않는다. 출처 헤더 위장·자동 로그인·우회 기법을 넣지 않는다.

이미 받은 자료에서 확인한 기술 사실:

- 가격 요청: `POST https://fconline.nexon.com/datacenter/PlayerPriceGraph`, 폼 `spid`, `n1strong`. `rd` 생략, 비로그인·기본 UA.
- 응답의 현재가: `.txt > span` 라벨 `현재가`와 형제 `strong[alt][title]`. alt/title에 쉼표가 포함된 **절대 BP 정수**가 있고 둘이 일치했다. 한글 축약값이나 차트의 만 단위 숫자로 변환할 필요가 없다.
- 이 HTML 조각은 선수/강화 식별자를 다시 명확히 표시하지 않는다. 파서에서 응답 ID를 검증했다고 허위 보고하지 말고 요청 provenance를 보존해야 한다.
- 표시 현재가를 거래 체결가·실구매 가능 가격으로 보장하지 않는다. `price_type`의 의미·신선도는 아직 확정하지 않았다. 보수적으로 unknown을 유지할 수 있다.
- 공식 팀컬러 목록의 클럽 ID: 리버풀 1001, 첼시 1003, 바이에른 뮌헨 1010. 목록에 각 클럽 4단계·11명과 보너스가 표시됐으나 단계별 전체 조건·현재 멤버 자격은 미검증이다.
