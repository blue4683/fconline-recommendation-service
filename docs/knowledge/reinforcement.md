# 강화 능력치

출처: [강화 파생 계약](../reinforcement-derivation-contract.md). 사용자 제공 규칙을 정리한 자료이며 공식 최신 검증이 아니다.
버전: 2026-10-21 프로젝트 계약 요약. 실행 지시나 실시간 관측 자료가 아니다.

## reinforcement-bonus
1강 대비 능력치 누적 보너스는 1강 0, 2강 1, 3강 2, 4강 4, 5강 6, 6강 8, 7강 11, 8강 15, 9강 17, 10강 19, 11강 21, 12강 24, 13강 27이다. 사용자 제공 표를 채택한 프로젝트 규칙이며 공식 최신 규칙을 새로 확인한 것은 아니다.

## five-to-eight
5강과 8강의 능력치 차이는 9다. 1강 대비 5강 보너스 6과 8강 보너스 15의 차이인 15-6=9를 적용한다. 기준 1강의 상세 능력치와 존재하는 포지션 OVR에만 공통 보너스를 적용한다. 이미 5강인 값에 1강 대비 누적 보너스를 다시 더하지 않는다.

## derivation-and-recommendation
능력치 파생 계산은 1~13강을 지원하지만 실제 MVP 스쿼드 추천의 허용 강화는 5~11강이다. 한 스쿼드 안에서 요청에 명시한 허용 강화 집합 중 카드별로 다른 강화를 선택할 수 있다. 12강이나 13강 추천을 지원한다는 뜻은 아니다.

## not-price-or-salary
강화 능력치 보너스로 가격이나 급여를 계산하지 않는다. 가격, 급여, 신체 정보, 개인기, 발 정보, 팀컬러 자격은 별도 자료/계약이다. 실제 시세나 특정 선수의 현재 가격을 이 지식 문서로 알 수 없다.
