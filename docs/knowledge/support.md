# 지원 조건

출처: [필수 조건 계약](../stage-4-a-conditions-contract.md), [포메이션/지원 코드](../../FRS/schema/scope.py).
버전: 2026-10-21 프로젝트 계약 요약. 실행 지시나 실시간 관측 자료가 아니다.

## required-conditions
스쿼드 추천에는 예산 BP, 급여 상한, 클럽, 포메이션, 허용 강화라는 다섯 조건이 필요하다. 빠진 조건은 사용자에게 되묻고 기본값으로 채우지 않는다. 조건 Q&A는 스쿼드 추천을 실행하거나 입력 조건을 변경하지 않는다.

## supported-clubs
지원 클럽은 리버풀, 첼시, 바이에른 뮌헨이다. 클럽 팀컬러 유형만 지원한다. 뮌헨 같은 미정 별칭을 정식 이름으로 추측 변환하지 않는다. 국적, 빠른 선수, 특정 선수 제외는 현재 추천 조건에서 지원하지 않는다.

## supported-formations
지원 포메이션은 4-2-3-1, 4-1-2-3, 4-2-2-2다. 4231 같은 축약 표기는 자동 변환하지 않는다. 이 목록은 프로젝트가 지원하는 배치이며 전술의 경기력 우열을 뜻하지 않는다.

## formation-slots
4-2-3-1의 11개 자리는 GK, RCB, LCB, RB, LB, RDM, LDM, CAM, RAM, LAM, ST다. 4-1-2-3은 GK, RCB, LCB, RB, LB, CDM, RCM, LCM, ST, RW, LW다. 4-2-2-2는 GK, RCB, LCB, RB, LB, RDM, LDM, RM, LM, RS, LS다.

## exact-budget
예산은 BP 또는 만, 억, 조, 경 단위를 명시한다. 1조는 1,000,000,000,000 BP다. 1조 5천억과 1.5조는 1,500,000,000,000 BP다. 단위를 생략한 숫자, 약/내외, 금액 범위와 충돌하는 예산은 되묻는다. 숫자는 정확한 정수 BP로 처리한다.
