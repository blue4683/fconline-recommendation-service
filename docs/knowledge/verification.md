# 스쿼드 검증과 자료 범위

출처: [엔진 계약](../stage-3-b-c-engine-contract.md), [스냅샷 계약](../stage-3-0-snapshot-contract.md), [발표용 범위](../ai-mini-project-results.md).
버전: 2026-10-21 프로젝트 계약 요약. 실행 지시나 실시간 관측 자료가 아니다.

## squad-constraints
스쿼드는 11개 자리에 각각 한 명을 배치하고, 선택한 클럽 자격을 전원이 충족해야 한다. person_id가 같은 인물은 시즌 카드나 강화가 달라도 최대 한 명이다. 전체 가격 합계와 급여 합계는 각각 요청한 상한 이하여야 한다. 등록 포지션의 승인된 같은 계열 슬롯만 기본 배치로 허용한다.

## score-and-optimality
성능 점수는 선택한 강화와 포지션의 OVR을 2로 나눈 값이다. CP-SAT의 목적은 스쿼드의 OVR 합 최대화다. OPTIMAL은 주어진 후보와 제약에서 최적성을 확인한 상태다. FEASIBLE은 조건을 만족하지만 최적성은 미확인이다. 점수와 최적성이 실제 경기력이나 승률을 보장하지 않는다.

## freshness-and-unknown
추천 자료의 자격이 미상이거나 기한이 지났거나 관측이 충돌하면 후보에서 제외한다. 명시 배치의 스냅샷을 사용하고 응답 전 유효기간을 재확인한다. 만료 자료를 자동 갱신하거나 다른 배치를 최신 자료로 골라 대체하지 않는다. Q&A 문서는 가격 관측이나 선수 자격의 출처가 아니다.

## synthetic-scope
발표 데모는 가상 선수, 가상 가격, 가상 급여와 자격 규칙으로 만든 합성 자료를 사용한다. 실제 선수 추천 품질과 실시간 시세를 검증한 서비스가 아니다. 공식 팀컬러 발동 단계/능력치 보너스와 실데이터 갱신 통합은 완료하지 않았다. 자료에 없는 선수 가격, 전술 우열과 외부 사실은 근거 부족으로 안내한다.
