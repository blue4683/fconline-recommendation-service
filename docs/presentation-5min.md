## 예상 질문

- **왜 합성 데이터인가?** 과제용 Agent 경로를 독립 검증하기 위해서다. 실데이터1-D/1-F와 제공자 허용 확인은 미완료다.
- **LLM이 선수도 선택하나?** 원문 후보 ID를 조건 필드에 연결한다. 최종 11명과 수치 계산은 코드/CP-SAT가 담당한다.
- **96%가 모델 정확도인가?** 전체25개 최종 응답 지표다. 준비 차단9개를 포함하며 실제 모델 대상의 근거/의미는15/16이다.
- **M02를 왜 실패로 세나?** 잘못된 추천은 차단했지만 기대한 예산 누락 안내를 제공하지 못했다.
- **MCP를 실제 모델이 호출했나?** 로컬 stdio 직접/도구 결과12사례를 대조했다. 일반 호스트 등록과 실제 LLM Tool-use는 미검증이다.
- **라이브 시연 가능한가?** 이번 자료는 저장 결과 설명이다. 종료된 실행의 잠금·호출 승인을 재사용하지 않는다. 새 라이브는 별도 범위를 정해야 한다.
