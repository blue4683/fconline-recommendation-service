# W8 RAG·LangSmith 추가 계약

2026-10-21 사용자 결정: 발표 전 추가 요소로 **RAG + LangSmith**를 선택했고 사용 가능한 LangSmith 계정·API 키가 있다고 답했다. 기존 25문장 평가/호출 승인·원문·결과는 보존한다. 이 문서는 새 경계를 정리하며 실제 모델 호출이나 외부 전송을 실행한 기록이 아니다.

## 확정 사실과 확인 중인 항목

| 구분 | 내용 |
|---|---|
| 사용자 확정 | RAG와 LangSmith 추가 구현. Multi-Agent는 이번 추가 범위에서 제외 |
| 사용자 확정 | LangSmith 계정·API 키 보유. 채팅으로 비밀값을 받지 않음 |
| 현재 코드 | qwen3:8b 로컬 조건 ID 선택·결정론 엔진·LangGraph·HTTP/SSE·MCP가 있음. 문서 검색/생성 경로는 없음 |
| 현재 코드 | langsmith==0.14.11이 고정 설치됐고 기존 추출/그래프는 tracing_context(enabled=False)로 보호됨 |
| 확인 중 | RAG를 별도 문서 Q&A API·CLI로 제공할지, 추천 후 자동 설명으로 붙일지 |
| 미실행 | 새 실제 추론·LangSmith 전송·서버/브라우저·키 설정·외부 제출 |

웹 요청 WEB-006(#94)을 읽었다. 두 노드만 나누어 독립 Multi-Agent라고 부르거나 로컬 JSON만 작성하고 LangSmith 연동 완료라고 보고하지 않는다. 새 경계는 통합 담당이 구현하고 웹 담당은 확정된 계약/fixture 뒤에 화면을 연결한다.

## RAG 경계 초안

추천하는 최소 기능은 프로젝트 문서에 근거한 규칙 Q&A다. 예: “지원 포메이션은?”, “5강과 8강의 능력치 차이는?”, “예산이 없으면 왜 되묻나요?” 실시간 시세·실존 선수 평가·게임 전술의 우열은 자료가 없으므로 답변 대상으로 확장하지 않는다.

1. 현재 계약에서 필요한 부분만 선별한 버전 고정 로컬 지식 문서를 작성한다. 개발 지침/비밀값/수집 원본/실제 모델 응답을 검색 corpus에 넣지 않는다. 허용 문서 목록·해시·문서/구간 ID를 고정한다.
2. 로컬 검색으로 관련 구간을 제한해 조회한다. 기존 scikit-learn의 문자 n-gram TF-IDF 등을 활용하면 추가 임베딩 모델/외부 검색/벡터 DB 다운로드가 필요하지 않다. 이것은 구현 후보이며 검색 품질을 검증해야 한다.
3. 기존 로컬 qwen3:8b를 재사용하는 안으로 검색 구간과 질문을 전달하고 답변/근거 ID를 받는다. 문서는 실행 지시가 아닌 근거 데이터다. 원문·출처를 덮어쓰지 않고 재시도/기본 지식 fallback은 사용하지 않는다.
4. 구조·구간 ID·인용의 검색 결과 포함 여부를 검증한다. 출처 ID 검증만으로 모든 자유 서술의 의미적 진실성을 보장한다고 보고하지 않는다. 근거 부족·모델 오류를 구분하고 알려진 정답/미지원/검색 실패 평가를 별도로 남긴다.
5. 강화 능력치 파생1~13과 추천5~11, 능력치와 가격/급여의 경계, 명시 배치/만료·동일 인물 조건을 유지한다. RAG 답변이 스쿼드 입력/배치/가격/검증 결과를 바꾸지 않는다.

Q&A 경로가 선택되면 엄격 DTO와 별도 명령/엔드포인트를 추가해 기존 추천 wire와 엔진을 유지한다. 자동 설명이 선택되면 호출 수·150초 전체 응답/취소·설명 실패가 스쿼드 응답에 미치는 영향을 먼저 확정한다. 상한·출력 필드는 최종 구현 계약에서 구체화한다.

## LangSmith 경계 초안

- 기존 그래프의 추적 비활성화를 전역 환경변수로 해제하지 않는다. 새 경로의 명시 관측기/내보내기 어댑터를 분리하고 기본은 꺼둔다. 환경에 키가 있다는 이유만으로 전송하지 않는다.
- 로컬 관측은 retrieval/generation/validation의 시작·종료·시간·결과 코드·제공된 토큰 집계처럼 허용한 필드만 생성하는 안이다.
- 외부 전송 초안은 단계명·시각/지연·상태/오류 코드·호출/토큰 수·corpus 버전/해시다. 질문·답변·검색 본문·선수 자료·API 키·로컬 파일 경로·예외 전문은 제외한다. SDK의 자동 runtime/환경 metadata도 통제한다.
- 원본 trace와 외부 payload를 구분한다. 실제 전송 전에 비밀값 없는 JSON 미리보기를 만들고 대상 endpoint/project·요청 상한을 함께 확인한다. 원문 숨김 설정을 켜는 것만으로 모든 metadata가 자동 보호된다고 가정하지 않는다.
- SDK 어댑터는 고정 버전과 대역 전송으로 검증한다. 오류를 무시하고 전송 성공을 주장하지 않는다. 제한된 실제 전송/수신 확인 후에만 실제 LangSmith 연동 완료로 기록한다.
- 로컬 기록의 기본 보관은 Git 제외·무기한이다. LangSmith 계정의 서버 보관/과금/권한 정책을 로컬 D2와 같다고 가정하지 않는다.

W8-4의 실제 호출/전송은 이전 소진 승인을 재사용하지 않고 미리보기와 실행 상한을 구체화한 뒤 진행한다. 기존 단위 테스트는 네트워크 대역만 사용하고 기능 PR은 pytest/Ruff/환경·최신 CI를 확인한다. 문서/계약 변경은 기능 변경과 별도 PR로 분리한다.

- [Multi-agent](https://docs.langchain.com/oss/python/langchain/multi-agent): 역할/문맥·위임 경계와 호출/지연 비용을 함께 다룬다. 이번 범위에는 구현하지 않는다.

위 문서의 최신 API를 설치된 SDK0.14.11에 그대로 가정하지 않고 실제 서명/대역 테스트로 호환성을 확인한다.
