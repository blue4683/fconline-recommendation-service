# Stage 1-C 카드 기본 데이터 축소 수집

2026-10-18, 실데이터 경로. 사용자는 추가 1,000명의 강화 5 기본 정보·클럽 이력을 최대 2,100 HTTP 시도·초당 최대 1회·차단/이상 즉시 중단 조건으로 **1회 승인**했다. 제공자 허용 확인은 미완료이며 이 승인을 후속 수집에 재사용하지 않는다.

## 범위

선수카드 식별자 `spid` 기준 1,000개를 추가한다. Stage 1-B에서 조회한 회귀 4 + 선별 200개 카드를 모두 제외한다. 같은 인물의 다른 시즌은 서로 다른 카드이며 동일 인물 배치 허용 규칙(D5)을 확정한 뜻은 아니다.

공식 공개 메타데이터를 한 번 읽고, 정렬·시드 `20261018`을 고정한 시즌별 순환 방식으로 표본을 정한다. 포지션별/급여별/팀컬러별 최소 수를 보장하는 Stage 1-D 층화 수집은 아니다. 정상 요청 수는 메타데이터 1 + 1,000명 × (능력치 1 + 클럽 이력 1) = **2,001회**다. 재시도도 2,100회 상한에 포함한다.

능력치 요청은 강화 5·성장/팀컬러 보정 0으로 고정한다. 파싱한 기본 카드·5강 급여·클럽/국가 이력을 로컬 파일에 보관하며 6~11강·가격·모델 학습·스케줄러·DB 적재는 실행하지 않는다. D8과 게임 내 팀컬러 자격이 미확정이므로 모든 추천 문서는 `unknown`, `valid_until=null`, `delete_after=null`이다.

## 체크포인트와 실패

- 고정 실행 ID `stage-1-c-20261018`, 원본 `data/raw/<ID>/`, 가공 `data/processed/<ID>/`. 실제 파일은 Git 제외 대상이다.
- 모든 HTTP 시도 전에 누적 수와 요청 자원을 manifest에 예약한다. 완료·차단·타임아웃·비정상 응답 중단은 새 실행이나 자동 재개로 반복하지 않는다.
- 프로세스 중단은 `--resume`으로 같은 실행만 재개한다. 기존 HTTP 200 응답은 원본 해시 검증 후 재사용하며, 완료 카드도 다시 요청하지 않는다. 메타데이터·표본·제외 목록·상한을 바꾸지 않는다.
- 프로세스가 요청 결과를 기록하기 전에 종료했다면 예약 시도를 차감하지 않는다. 그 시도는 `interrupted`, HTTP 상태·소요 시간 미상으로 기록한다. 미상 소요 시간을 0으로 채우지 않도록 `CrawlLog.duration_ms`는 명시적 null을 지원한다.
- 카드별 가공 파일은 임시 파일에서 원자적으로 교체하고 해시를 checkpoint에 기록한다. 원본/가공 해시가 달라지면 재개를 거부한다.
- 파일 잠금으로 동일 실행의 동시 시작·재개를 막는다. 잠금은 macOS·Linux의 `fcntl`을 사용한다. Windows 실행은 미지원·미검증이다. 호스트 전원 장애까지의 디스크 내구성을 보장한 것은 아니다.
- 502/503/504에 한해 1회 재시도한다. 403/429·연결 오류·timeout·지연·비정상 응답·파싱 실패는 중단한다. 선택한 카드의 404도 완료 카드 수를 채운 것으로 처리하지 않는다.

## 실행

```sh
# 네트워크 없는 계획 출력
python -m FRS.utils.crawling.collect_cards
# 승인된 1회 수집
python -m FRS.utils.crawling.collect_cards --run
# 프로세스 중단 체크포인트만 같은 상한으로 재개
python -m FRS.utils.crawling.collect_cards --resume
# 완료 결과를 네트워크 없이 원본과 대조
python -m FRS.utils.crawling.verify_collection
```

이미 완료했거나 차단/이상으로 중단한 경로를 삭제·변경해 재수집하지 않는다. HTTP 클라이언트 기본 UA, 인증 키/로그인/프록시/netrc 없음, 리다이렉트 추적 없음, 순차 요청이라는 Stage 1-B 정책을 유지한다.

## 검증

합성 응답으로 정상 수집, 고정 시즌 표본, 프로세스 중단 재개·HTTP 응답 재사용·누적 상한 보존, 결과 미상 시도, 403/429 재개 금지, 상한 직전 재시도, 원본/가공 변조와 동시 실행 거부를 검증한다. 기존 1-B 테스트도 유지한다.

실제 결과는 진행 후 기록한다.
