# Stage 1-D 층화 카드 상세·강화 보강

2026-10-19. 실데이터 경로의 부분 증분이다. **수집 실행 중이며 완료·원본 대조 전이다.** Stage 1-D 전체를 완료로 표시하지 않는다.

## 승인 범위

사용자는 저장된 세 클럽 목록에서 층화 선별한 최대 260개 카드의 5~11강 전체 능력치·클럽 경력 수집을 새 예외로 1회 승인했다. 최대 2,100 HTTP 시도·순차 초당 최대 1회·재시도 없음·302/403/429 및 모든 오류 즉시 중단·로그인/출처 위장 없음·로컬 무기한 보관이다. 미상 요청도 상한에서 제외하지 않는다. 제공자 허용 0-B는 미확정이다.

이전 완료/중단 실행의 남은 횟수를 사용하지 않는다. 가격을 다시 조회하거나 페이지 전체를 순회하지 않으며 DB 적재·학습·지속 수집·스케줄러도 실행하지 않는다. 모든 구간의 N=3 달성을 보장하지 않는다. `status=unknown`, `valid_until=null`, `delete_after=null`을 유지한다.

## 선별과 구현

기존 완료 실행 `stage-1-d-salary-filter-20261019`의 원본 해시·전체 15개 쿼리·급여 구간·클럽/강화/페이지 조건을 검증한다. 같은 카드의 급여·표시 포지션 OVR가 충돌하면 선별을 중단한다. 사용한 원본 manifest의 SHA-256을 새 실행에 고정한다.

각 카드가 포함된 클럽 × 급여 구간 × 표시 포지션 칸을 만들고, 아직 목표 수를 채우지 못한 칸을 가장 많이 보강하는 카드를 순서대로 고른다. 동률은 spid 오름차순이며 무작위·추천 점수로 선별하지 않는다. 후보 수가 3보다 적은 칸은 관측 가능한 수까지만 선별하고 부족 사실을 숨기지 않는다. 이 방식은 현재 목록 안의 자료 확보 순서이며 제품의 배치/점수 정책이나 최적해 보장이 아니다.

후보 1,930개에서 **259개**를 선별했다. 목록에 비어 있지 않은 칸은 206개, 후보가 3개 이상인 칸은 167개다. 선별 후 목록 안에서 도달 가능한 목표의 잔여 수는 0이지만 **검증된 등록 포지션·공식 자격에 대한 N=3 달성을 뜻하지 않는다.** 전체 420칸의 자료 확보와도 다르다.

정상 계획은 카드당 PlayerAbility 7회(5~11강)와 PlayerInfo 1회로 **2,072회**다. 새 메타데이터·목록·가격 요청은 필요하지 않다. HTTP 기본 UA·환경 프록시/netrc 미사용·리다이렉트 추적 없음·재시도 0회다.

- 구현: `FRS/utils/crawling/enrich_cards.py`.
- 원본 대조: `FRS/utils/crawling/verify_enrichment.py`.
- 실행 ID: `stage-1-d-enrichment-20261019`.
- 원본: `data/raw/stage-1-d-enrichment-20261019/`.
- 가공: `data/processed/stage-1-d-enrichment-20261019/`.
- 실행 출력: `data/raw/stage-1-d-enrichment-20261019.console.log`.

새 수집기는 기존 수집기의 요청 예약·원본 해시·로그·동시 실행 잠금을 재사용한다. 요청 전 누적 시도를 먼저 저장하고, 받은 원본은 재개 시 재요청하지 않는다. 카드별로 기본 카드 1개·강화별 급여 7개·기준 5강과 연결한 강화 차이값 7개·미검증 클럽 경력/국적을 원자적으로 저장한다. 가격 관측은 별도의 기존 목록 배치를 유지하며 기본 카드 버전으로 가장하지 않는다.

같은 실행의 프로세스 중단은 선별·정책·누적 상한·기존 응답 해시를 유지한 경우에만 재개할 수 있다. 결과 미상/실패 요청이 있으면 재시도 없이 재개를 거부한다. 완료·차단/이상으로 중단한 실행의 자동 재시작을 금지한다.

## 실행과 재현

```sh
# 저장된 근거를 읽어 계획만 출력한다. 네트워크 요청 없음.
.venv/bin/python -m FRS.utils.crawling.enrich_cards
# 승인된 1회 수집. 이미 시작한 실행에는 다시 사용하지 않는다.
.venv/bin/python -m FRS.utils.crawling.enrich_cards --run
# 프로세스 중단에 한해 가드 통과 후 같은 실행을 재개한다.
.venv/bin/python -m FRS.utils.crawling.enrich_cards --resume
# 완료 후 네트워크 없이 원본/가공/로그를 대조한다.
.venv/bin/python -m FRS.utils.crawling.verify_enrichment
```

검증기는 선별 근거·2,100회 상한·재시도 0·직렬 로그·요청 간격·URL/폼 provenance·원본/가공 해시를 검사한다. 모든 강화의 능력치 34개를 직접 표시값과 대조하고 기본 카드·급여·강화 차이값·기준 버전·클럽 경력을 재파싱해 가공 문서와 비교한다. 완료 전에는 검증 완료로 보고하지 않는다.

## 검증 현황과 남은 제한

수집 시작 전 pytest 326개·Ruff 린트/포맷·환경 import·pip 검사를 통과했다. 오프라인 검증기 추가 후 전체 pytest 334개·Ruff 린트/포맷도 통과했다. 실제 원본 검증 결과는 종료 후 갱신한다. 합성 테스트는 다중 강화 연결, 선별 재현/충돌, 범위 밖 요청 거부, 302/403/404/429/500/503 즉시 중단·재시도 없음, 요청 상한·결과 미상 중단·응답 재사용·원본/가공/provenance/로그 변조 탐지를 포함한다. 실제 HTML·선수별 가공 결과를 테스트 fixture나 커밋에 넣지 않는다.

수집 완료 여부·실제 요청 수·원본 대조 수치·기존 자료와의 중복·5강 경력 기반 커버리지는 종료 후 기록한다. 팀컬러 검색 결과를 발동 자격으로 채택하는 계약, 추천 신선도 D8, 가격 의미와 Stage 1-F는 여전히 미확정이다.
