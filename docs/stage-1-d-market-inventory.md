# Stage 1-D 가격 파서와 관측 재고 — 진행 중

2026-10-19 재개. 현재 경로는 실데이터이며 이번 증분은 **이미 저장한 자료의 오프라인 처리**다. 신규 넥슨 요청·반복 수집·DB 적재·학습·스케줄러는 실행하지 않았다. Stage 1-D 전체를 완료한 것은 아니다.

## 사용자 결정

2026-10-18 답변을 재개 후 설계도 §5·§11에 반영했다.

- 우선 클럽: 리버풀·첼시·바이에른 뮌헨.
- 급여 구간: 20 이하 / 21~25 / 26~30 / 31~35 / 36 이상.
- 등록 포지션 × 급여 구간 × 클럽별 목표 최소 수 N=3. 서로 다른 spid 기준이며 부족한 칸을 보고한다.
- 같은 카드의 여러 강화 단계를 여러 카드로 세지 않는다. 같은 인물의 다른 시즌은 다른 spid다. 동일 인물 배치 규칙(D5)을 결정한 뜻은 아니다.

Stage 1-B·1-C의 수집 예외는 사용을 마쳤다. Stage 1-D의 신규 대량 수집 범위·상한은 승인받지 않았다.

## 가격 파서

`FRS/utils/crawling/price_parser.py`는 라벨이 정확히 `현재가`인 `.txt` 영역의 직접 자식 `strong`에서 `title`과 `alt`를 읽는다. 두 정수 속성이 일치해야 하며 영역 누락·중복·형식 오류·상충 값·0·지원 BP 범위 초과를 거부한다. 부동소수점·한글 축약표기·차트 값을 가격으로 대체하지 않는다. BSON Decimal128까지 큰 정수를 손실 없이 왕복 검증했다.

선수·강화 식별은 저장된 요청 URL·폼 기록을 따르며 응답 바이트 SHA-256을 version으로 보존한다. 응답 HTML이 식별자를 다시 표시하지 않으므로, 파서가 응답 선수 ID·강화를 직접 대조했다고 주장하지 않는다.

파싱 성공은 거래 체결가나 실구매 가격 검증이 아니다. 현재 파서는 `price_type=unknown`, `status=unknown`, `valid_until=null`을 유지한다. 호출 문맥에 유효기간이 있어도 이를 근거로 가격을 ok로 승격하지 않는다. 미인식 0·빈 값 등을 임의로 무료 또는 거래 불가로 분류하지 않는다.

## 관측 재고 집계

`FRS/diagnostics/coverage.py`는 **클럽 경력 기준 관측 재고**를 순수 함수로 만든다. 아직 공식 멤버 자격이 없기 때문에 모든 결과에 `basis=club_career_history`, `coverage_status=unverified`, `recommendation_ready=false`를 기록한다.

- 기본 카드와 같은 batch_id·spid·강화·응답 version의 급여만 연결한다. 클럽 경력은 같은 batch_id·spid와 정확한 클럽 이름으로 연결한다.
- 서로 다른 관측이 충돌하면 최신값을 임의로 선택하지 않고 명시적 스냅샷을 요구한다. 동일한 중복 입력은 카드 수를 늘리지 않는다.
- 미래에 관측한 값과 삭제 기한에 도달한 기록은 제외한다. 신선도가 지난 관측은 역사적 재고에는 남길 수 있지만 추천 가능으로 판정하지 않는다.
- 카드의 모든 등록 포지션에 한 번씩 기여한다. 같은 칸에는 같은 spid를 한 번만 센다. 포메이션의 좌우 슬롯이나 점수 그룹으로 코드를 변환하지 않는다.
- 포지션 universe는 스키마의 28개 정규 코드다. 관측하지 못한 코드·구간·클럽 조합도 0으로 남겨서 빈 칸을 숨기지 않는다. 등록 CB가 있다는 이유로 RCB·LCB를 채우지 않는다. 배치 허용은 D5의 별도 결정이다.
- 기본값은 강화 5 기준이다. 강화 6~11의 급여를 5강 기본 카드에 붙이지 않는다. 다른 단계 집계는 해당 단계로 관측한 기본 카드가 있어야 한다.
- `observation_gap=max(0, 3-observed_cards)`는 관측 수의 부족분이다. 0이어도 공식 자격·가격·신선도·추천 후보 검증이 끝났다는 뜻이 아니다.

## 로컬 보고 도구

```sh
python -m FRS.diagnostics.local_market_report
```

기존 1-B·1-C 완료 자료의 원본/가공 해시·스키마·숫자 대조를 먼저 수행한다. 저장된 1-D 확인 자료에서도 가격 요청 폼과 원본 해시를 확인한다. 이 도구는 네트워크를 사용하지 않으며 중단 manifest를 수정하거나 수집을 재개하지 않는다.

기본 출력은 Git 제외 `data/processed/stage-1-d-local-report/`의 `coverage.json`, `price_observations.jsonl`이다. `--at`에는 시간대가 포함된 ISO 시각, `--output`에는 파생 보고서 경로를 지정할 수 있다. 실제 자료는 커밋하지 않는다.

가격 2건은 앞서 확인한 한 회귀 카드의 5·11강 관측이며, 우선 세 클럽의 가격 커버리지 달성으로 세지 않는다. `FC 바이에른 뮌헨 II` 같은 별도 이름도 바이에른 뮌헨에 합치지 않는다. 이 집계로 추가로 필요한 HTTP 수를 확정할 수는 없다. 먼저 공식 자격과 필요한 관측 대상을 확인해야 한다.

## 중단된 공식 조회

2026-10-18의 소량 확인은 6번째 요청에서 stopped 상태가 됐다. 공개 가격 2건·팀컬러 목록·공식 JS 2개는 200이었다. 공식 JS가 호출하는 `/datacenter/TeamColorDetail?teamcolorid=1001`은 302로 오류 페이지를 가리켰다. 오류 페이지 추적·동일 호출 재시도·나머지 클럽 상세 HTTP 호출은 하지 않았다.

원인은 미확정이며 로그인 요구 또는 403/429 차단으로 단정하지 않는다. 새 실행 ID나 헤더 위장으로 중단 가드를 우회하지 않는다. 현재 저장된 공식 목록에서 세 클럽 ID와 4단계·11명 표시를 관측했으나, 단계별 조건·멤버 자격 전체가 확정된 것은 아니다.
