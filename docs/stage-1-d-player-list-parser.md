# Stage 1-D 선수 목록 파서와 급여 필터 검증

2026-10-19. 실데이터 경로의 **부분 증분**이다. 목록 순수 파서와 저장 응답 보고 도구를 구현하고, 사용자가 별도로 승인한 1회 소량 진단을 완료했다. Stage 1-D 전체는 미완료다.

## 구현 계약

- `FRS/utils/crawling/player_list_parser.py`의 `parse_player_list`는 HTTP·DB 접속 없이 목록 HTML과 명시적인 관측 context를 받는다.
- 행 ID, 요청/표시 강화, 급여, 표시 포지션별 OVR, 목록 OVR, 선택 능력치 네 열, 강화 5~11의 정수 가격 속성을 검증한다. 중복 카드/포지션/필수 영역·형식 변경·가격 속성 충돌·누락은 오류다.
- 일부 행에는 포지션이 여러 개 표시된다. 모두 `listed_position_ovr`에 보존하고 첫 표시를 `primary_position`으로 기록한다. 전체 등록 포지션임을 보장하지 않는다. 기존 리버풀 200행 중 78행이 복수 표시였다.
- 능력치 열은 요청 `strSkill1..4`와 응답 `data-type`이 일치해야 한다. 확인한 속력·가속력·몸싸움·스태미너만 지원하며 기존 스키마 키를 유지한다. 전체 34개 능력치로 대체하지 않는다.
- OVR 직접 숫자와 괄호 안 기본 OVR를 분리한다. 가격은 축약 텍스트를 사용하지 않고 alt/title의 동일한 절대 BP 정수를 읽는다. 기존 가격 파서와 정수 변환 함수를 공유한다.
- 가격 0은 유효한 양의 BP가 아니므로 `price=null`, `status=unknown`으로 보존한다. 거래 불가로 단정하지 않는다. 속성 누락·비정수·충돌을 0으로 바꾸지는 않는다.
- 목록 결과는 별도의 `PlayerListRow`다. `PlayerCard`나 `CardSalary`로 자동 적재하지 않는다. 목록 원본 해시를 기존 능력치 카드의 버전으로 가장하지 않는다. 가격 문서도 원본 해시·배치·출처·관측 시각을 그대로 갖는다.
- 가격 의미·D8 신선도는 미확정이다. 모든 결과는 `unknown`, `valid_until=null`이며 추천 가능 상태로 승격하지 않는다. 원본·가공 결과는 Git 제외 로컬 무기한 보관한다.
- 정상 빈 목록 구조는 아직 확인하지 못했으므로 카드 영역이 없는 응답을 정상 0건으로 처리하지 않는다. HTML 오류 페이지를 성공으로 오인하지 않기 위한 제한이다.

## 새 진단의 승인과 실행

사용자가 목록 파서 구현 후 **세 클럽 급여 필터 검증 1회·최대 20 HTTP 시도·초당 최대 1회·302/403/429 및 오류 즉시 중단·재시도/로그인/출처 위장 없음·로컬 보관**을 승인했다. 페이지 전체 순회·선수 상세 대량 보강·학습·새 대량 수집은 제외한다. 제공자 허용 0-B는 여전히 미확정이다.

실행 ID는 `stage-1-d-salary-filter-20261019`다. **15/20회 모두 200으로 완료**했고 남은 5회는 재사용하지 않는다. 이전 완료/중단 실행도 재개하지 않았다. 요청 시작 간격 최솟값은 **1.479412초**, 오류·리다이렉트·재시도는 없었다.

기존 검증 공식 JS의 해시와 폼 기록을 대조해 `POST /datacenter/PlayerList`를 사용했다. 이번에 JS를 새로 받은 것은 아니다. `n4LeagueId=0`, `n4TeamId` 빈 문자열, `strTeamColorCategory=affiliation`, `n1Strong=5`, `n4PageNo=1`을 유지하고 팀컬러 ID와 급여 하한/상한만 변경했다. 클럽 ID와 팀컬러 ID를 혼동하지 않았다. 나머지 조건은 기존 검증 폼을 유지했으며, 1강 가격 상한 등 기존 검색 제한까지 제거한 무조건 전체 조회는 아니다.

| 클럽(팀컬러 ID) | 4~20 | 21~25 | 26~30 | 31~35 | 36~99 | 클럽별 고유 카드 |
|---|---:|---:|---:|---:|---:|---:|
| 리버풀(1001) | 200 | 200 | 200 | 44 | 22 | 666 |
| 첼시(1003) | 200 | 200 | 200 | 68 | 27 | 695 |
| 바이에른 뮌헨(1010) | 200 | 200 | 200 | 68 | 23 | 691 |

15개 응답 **2,052행 모두 요청 급여 범위에 들어갔다.** 응답 내 중복 ID는 없었다. 클럽 간 중복을 제거하면 **고유 카드 1,930개**, 카드×강화 가격 키 **13,510개**다. 0으로 표시된 고유 가격 키 245개는 미상이며, 나머지 13,265개는 양의 정수 관측이다. 중복 가격 키 사이의 관측 값 충돌은 없었다. 가격 의미와 신선도를 확인했다는 뜻은 아니다.

기존 기본 카드 1,104개와 ID가 겹치는 것은 **132개**, 기존 기본 정보가 없는 신규 후보는 **1,798개**다. 이 교집합은 ID 기준이며 132개 전체의 최신 능력치·자격을 검증한 것으로 세지 않는다. 기본 카드 저장 개수가 3,034개로 증가한 것도 아니다.

사용자 정책의 끝 구간은 ‘20 이하/36 이상’이지만 이번 진단은 사용자 제공 폼의 유한 범위 **4~20/36~99**를 사용했다. 1~3 또는 100 이상에 대한 범위 검증은 하지 않았다. 급여 범위 내 반환은 확인했으나 범위의 모든 카드를 반환했는지는 확인하지 못했다. 특히 9개 응답은 여전히 200행이며, 이전 페이지 1/2가 같았던 제한도 남는다.

## 재현과 근거

저장된 자료만 다시 파싱한다. 아래 명령은 네트워크·DB 요청을 보내지 않는다.

```sh
.venv/bin/python -m FRS.diagnostics.player_list_report data/raw/stage-1-d-player-search-pilot-20261019
.venv/bin/python -m FRS.diagnostics.player_list_report data/raw/stage-1-d-salary-filter-20261019
```

보고 도구는 종료된 실행의 요청 URL·POST·200 상태·파일 경로·SHA-256을 검사한다. 원본 관측 시각과 배치를 유지하고 같은 카드가 여러 요청에 나와도 고유 가격 키로 중복 집계하지 않는다. 충돌 관측을 합쳐 하나의 유효 가격으로 고르는 도구는 아니다. `complete=false`를 명시한다.

로컬 근거는 다음 경로다. 실제 HTML·선수별 가공 JSON은 커밋하지 않는다.

- `data/raw/stage-1-d-salary-filter-20261019/manifest.json`: 승인·누적 시도·전체 폼·응답 해시·시각·구간별 결과.
- 같은 원본 디렉터리의 `inspection.py`: 1회 가드·상한·중단 정책을 적용한 실제 진단 스크립트. 이미 완료한 실행이므로 재실행하지 않는다.
- `data/processed/stage-1-d-salary-filter-20261019/`: 부분 관측 JSON과 `assessment.json`. 가공 파일 해시·내용을 새 파서 결과와 대조했다.

기존 4개 목록 응답도 원본 해시 확인 후 총 800행을 파싱했다. 고유 카드 200개·가격 키 1,400개로 이전 집계와 일치했다. 기존 원본 시각을 새 관측으로 바꾸지 않았다.

## 검증과 남은 작업

합성 테스트는 정상 5/11강, 복수 포지션, 괄호 OVR, 큰 정수 BP/BSON 왕복, 0 가격 미상, ID/강화/OVR/능력치 충돌, 누락·중복·오류 페이지, 저장 해시/경로 변조와 미종료 실행 거부를 포함한다. 전체 **pytest 304개**, Ruff 린트·포맷, 환경 import·pip 의존성 검사를 통과했다. 실제 응답을 단위 테스트 fixture에 넣거나 테스트 중 외부 요청을 보내지 않았다. 원격 CI와 병합은 최신 PR head에서 별도로 확인한다.

다음은 신규 후보의 층화 선별과 기존 상세/능력치 파서 연결이다. **신규 후보 1,798개에 대한 상세·강화 6~11 수집은 이번 승인에 포함되지 않는다.** 새로운 수집이 필요하면 카드 수·총 HTTP 상한·중단 정책을 별도로 확인한다. 저장된 후보만으로 계획을 작성하는 작업은 외부 요청 없이 가능하다. 팀컬러 검색 결과를 자격으로 채택하는 계약·발동 규칙, 목표 N=3 달성 여부, 가격 의미·신선도, 1-F는 미완료로 유지한다.
