## 승인과 실행 제한

- 새 실행 1회, 공식 팀컬러 페이지·현재 JS·상세·멤버 목록과 가격 소량 확인을 합쳐 최대 10 HTTP 시도.
- 순차 초당 최대 1회. 302/403/429·오류·연결 이상·급격한 지연 즉시 중단. 재시도·자동 리다이렉트 추적 없음.
- HTTP 클라이언트 기본 UA, 동일한 비로그인 HTTP 세션. 로그인·출처 헤더 위장·프록시·netrc 사용 없음.
- 과거 실행과 원본 보존. 원본·요청 기록·검사 스크립트는 Git 제외 로컬에 무기한 보관.
- 대량 수집을 포함하지 않으며 제공자 허용(0-B) 미확정도 유지.

## 확인 범위와 해석

새 비로그인 HTTP 세션에서 공식 목록을 먼저 읽고 현재 페이지가 직접 참조한 JS의 상세 요청 경로를 확인했다. 상세 요청에는 확인한 teamcolorid를 넣었다. JS의 캐시 무효화용 난수 매개변수는 생략했고 브라우저의 JavaScript·jQuery는 실행하지 않았다. 일반 브라우저에서 정상 UI를 조작한 요청과 완전히 같다고 주장하지 않는다.

새 실행에서도 직접 HTTP 상세 요청이 오류 페이지로 연결됐다는 사실을 확인했다. 입력·브라우저/AJAX 문맥·서버 동작 중 어느 것이 원인인지는 확정하지 못했다. 모든 사용자의 공식 UI가 고장 났다거나 로그인 필수·접근 차단이라고 단정하지 않는다.

같은 오류가 반복되어 요청 조건을 계속 바꾸거나 다른 경로로 범위를 넓히지 않았다. 후속 조사에는 정상적인 공개 브라우저 UI에서 상세 팝업이 열리는지와 그 요청 계약에 대한 근거가 필요하다. 이번 종료를 새 수집이나 추가 조회 승인으로 확대하지 않는다.
