# Stage 1-F 가격 의미·팀컬러 자격 관측 계약

2026-10-19 사용자 확정 결정이다. D8 기간·수동 운영·첫 259카드 범위는 [신선도 정책](stage-1-f-freshness-policy.md)을 유지한다. 이번 결정도 새 외부 요청이나 스케줄러 실행 승인이 아니다.

## 참고가격

공식 선수 목록의 표시 가격을 추천용 **참고가격(`reference`)**으로 채택한다. 거래 체결가·즉시 구매 가능한 가격을 보장하지 않는다. 이후 검증된 새 배치에서 양의 정수 표시값은 원본/식별/가격 속성 검증과 D8 기한을 함께 충족해야 추천 사용을 허용할 수 있다.

0·누락은 `unknown`으로 제외하며 거래 불가로 단정하지 않는다. 형식 변경·ID/강화 충돌·가격 속성 불일치 등의 파싱 오류는 기존 즉시 중단 정책을 따른다. 누락을 0으로 채우거나 다른 가격을 가져와 대체하지 않는다.

## 클럽 자격 관측

공식 **소속 팀컬러 필터 결과에 포함된 카드 ID**를 클럽 팀컬러 자격의 관측 근거로 채택한다. 검증된 teamcolorid와 affiliation 조건, 요청/응답 provenance를 보존한다. 현재 우선 클럽은 리버풀 1001·첼시 1003·바이에른 뮌헨 1010이다. 클럽 ID와 팀컬러 ID를 혼동하지 않는다.

클럽 경력은 보조 대조 자료로만 사용한다. 경력만으로 자격을 만들지 않으며, 팀컬러 목록의 첫 응답에 없다는 사실만으로 자격 상실을 판정하지 않는다. 필터는 반환된 카드의 양성 관측 근거이며 전체 자격 명단의 전수성을 보장하지 않는다.

사용자는 이 근거를 채택하기 전, 새 보강 표본의 306개 카드-클럽 쌍이 경력과 일치한 대조 결과를 확인했다. 이는 표본 대조이며 모든 카드의 게임 내 수동 검증으로 보고하지 않는다. 발동 인원·단계·강화/시즌 예외·능력치 보너스 규칙은 별도 미확정이다.

## 기존 자료와 적용 범위

기존 원본·unknown 가공 배치는 유지하고 **이후 검증된 새 배치**부터 적용한다. 기존 배치에 가격 의미·유효 기한을 덮어쓰거나 재파싱 시각을 새 관측 시각으로 사용하지 않는다. 새 관측도 원본 검증·참고가격/자격 계약·D8을 모두 충족해야 하며 기간 설정만으로 품질 검증을 생략하지 않는다.

관측 원본·출처·배치·시각·해시를 유지하고 새 batch_id로 저장한다. 명시 배치 조회와 중복/충돌 관측 제외는 유지한다. 최신 가격·최신 자격·활성 스냅샷을 자동 선택하는 정책을 새로 도입하지 않는다.

## 다음 구현과 검증

이 문서는 사용자 결정을 기능 PR과 분리해 기록한다. 새 관측의 가격·자격 정규화와 수동 갱신 실행기는 후속 구현이며, 현재 갱신 계획 명령은 네트워크 요청을 보내지 않는다. 실제 실행은 출처별 요청량·총 상한·중단 조건이 승인된 범위에서만 가능하다.

문서 경로·링크·Git diff와 사용자 답변의 일치를 확인한다. 문서만 변경하므로 로컬 기능 검사는 재실행하지 않는다. 정책 채택은 실제 갱신 검증 완료나 Stage 1-D·1-F 전체 완료를 뜻하지 않는다.
