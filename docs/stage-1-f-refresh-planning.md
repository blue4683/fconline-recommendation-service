# Stage 1-F 기한 판단·수동 갱신 계획

2026-10-19. [확정 정책](stage-1-f-freshness-policy.md)을 코드에 반영한 부분 증분이다. **기한 판단과 오프라인 갱신 계획 명령만 구현**했다. 실제 갱신 실행기·스케줄러·삭제·DB 적재·학습은 실행하지 않았으며 Stage 1-F 전체는 미완료다.

## 구현

`FRS/core/freshness.py`는 D8 정책을 불변 규칙으로 보관한다. 가격 유효 24시간/갱신 12시간, 급여·능력치·검증된 자격 유효 7일/갱신 3일이다. 정책 명세와 해시도 반환한다.

시각은 시간대가 필요하며 UTC에서 계산한다. 원래 관측 시각에 기간을 더하고 갱신/만료 경계는 해당 시각 **이상**이다. 미래 관측은 사용 가능하지 않다. `assess`는 기존 문서의 상태·기한·삭제 기한과 정책을 함께 평가해 더 짧은 조건을 따른다. 기존 기한을 늘리거나 원본을 수정하지 않는다. unknown·가격 의미·자격 검증을 이 함수가 대신하지 않는다. 기존 1-E 검색 코드의 동작을 이번 증분에서 바꾸지는 않았다.

`FRS/utils/crawling/refresh_plan.py`는 고정한 완료 배치의 259개 카드만 관리한다. 현재 단계에는 `--run`이나 자동 실행 경로가 없다.

```sh
# 저장 원본·가공·선별·로그를 검증한 뒤 갱신 계획 출력. 외부 요청 없음.
.venv/bin/python -m FRS.utils.crawling.refresh_plan --plan
# 명시한 시각에서 동일한 계획을 재현한다.
.venv/bin/python -m FRS.utils.crawling.refresh_plan --plan --at '2026-10-19T13:36:25.451606+09:00'
```

기본값도 계획 출력이다. 전체 원본을 재검증하므로 로컬 자료 읽기·파싱에 시간이 걸릴 수 있다. 다른 배치를 자동으로 최신 선택하지 않는다. 입력 배치 ID·manifest 해시와 정책 해시를 결과에 담는다.

대상 카드·강화별 관측의 누락/중복·기준 버전 충돌·가격 값 충돌·배치 불일치·미래 관측은 오류다. 같은 가격을 여러 클럽 쿼리에서 관측한 경우 원본을 유지하고 **계획 시각만 가장 이른 관측 기준으로 보수적으로 계산**한다. 최신 가격을 선택하거나 새 추천 스냅샷으로 병합하지 않는다.

출력의 `policy_expires_at`은 D8로 계산한 **계획용 시각**이다. 과거 문서의 `valid_until`을 새로 부여하거나 `unknown`을 `ok`로 바꿨다는 뜻이 아니다. 실제 기한과 자격이 확인된 문서의 추천 가능성은 별도 평가해야 한다.

## 출처별 요청량 제안

| 갱신 묶음 | 제안 경로 | 전량 갱신 시 예상 시도 |
|---|---|---:|
| 표시 가격 | 기존 세 클럽 × 다섯 급여 구간의 PlayerList 첫 응답 | 15 |
| 능력치·급여 | 관리 카드 259개 × PlayerAbility 5~11강 | 1,813 |
| 팀컬러 자격 | 검증된 갱신 출처/채택 계약 미확정 | 계획 차단 |

합계 **1,828회는 실행 상한 승인값이 아닌 요청량 추정**이다. 능력치와 급여는 같은 응답에서 읽으므로 요청을 중복 계산하지 않는다. PlayerInfo의 클럽 경력 재조회는 이 제안에 포함하지 않는다. 경력만으로 자격을 갱신할 수 없기 때문이다.

목록 첫 응답은 전체성을 보장하지 않으므로 미래에 같은 15회로 관리 카드의 모든 가격을 다시 찾는다는 보장도 없다. 누락 시 추가 페이지·단건 가격·새 후보 요청으로 자동 확대하지 않는다. 실제 실행기와 누락 처리·부분 실패 적용 계약을 정할 때 확인할 제한이다.

자동 실행·추가 수집 승인은 없다. 실제 외부 갱신은 새 요청량·총 상한·중단 조건이 확정된 범위에서 별도로 실행해야 한다. 현재 모든 이전 수집 예외는 종료 상태를 유지한다.

## 실제 로컬 검증

네트워크 소켓과 requests 전송을 차단한 상태에서 실제 완료 배치를 읽어 명령을 실행했다. 기준 시각은 **2026-10-19 13:36:25.451606 KST**다.

- 관리 카드 259개, 가격 키 1,813개. 0 표시에서 보존한 미상 가격 키 154개.
- 읽은 프로필/가격 관측 6,027개는 모두 원래 `unknown`이었다. 변경하지 않았다.
- 가격 묶음의 가장 이른 관측은 10월 19일 09:41 KST, 갱신 예정은 **10월 19일 21:41 KST**다.
- 능력치/급여 묶음의 가장 이른 관측은 10월 19일 09:53 KST, 갱신 예정은 **10월 22일 09:53 KST**다.
- 이 기준 시각에서 예정 시점이 지난 갱신 요청은 **0회**, 실제 전송도 **0회**다. 이는 정책 계산 결과이며 추천 데이터가 사용 가능하다는 판정은 아니다.
- 팀컬러 자격 갱신은 `verified_eligibility_source_unconfirmed`로 차단했다. 경력 관측을 자격으로 승격하지 않았다.

결과는 Git 제외 `data/processed/stage-1-f-refresh-plan.json`에 보관한다. 실제 원본과 선수별 자료를 fixture나 커밋에 포함하지 않는다.
