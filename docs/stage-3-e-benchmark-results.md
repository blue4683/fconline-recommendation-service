## 문제 구성과 판정

각 포메이션마다 정규 해 존재10개·해 없음5개·작은 전수 대조5개로 총60개다. 정규 후보 규모는 자리당 서로 다른 카드3/10/30개다. 같은 등록 계열의 좌우 슬롯은 같은 풀을 사용한다. 카드당 하나의 관측 강화를 5~11 사이에서 부여해 카드 수와 실제 강화별 후보 수를 기록한다. 큰 BP도 포함하며 금액은 Python 정수다.

해 존재30개와 작은15개는 11인 기준 스쿼드를 먼저 독립 검증했다. 해 없음은 빈GK·가격/급여 합계 하한 미달·10인 이하 인물 수·필수 자리의 동일 인물 충돌을 각 포메이션에 구성했다. 작은 문제는 제약을 위반한 부분 선택만 가지치기하고 모든 가능한 완성 선택의 OVR 최댓값을 열거했다. 후보 누락이나 생성 오류를 해 없음의 증거로 바꾸지 않는다.

CP-SAT과 두 탐욕 방식은 같은 스냅샷을 쓰고 반환해를 다시 독립 검증한다. 상태 정확도는 알려진 해 존재/해 없음·원래 종료 상태·반환 결과의 의미를 대조한다. truthful UNKNOWN은 해 없음으로 해석하지 않으며 유효해 반환율에서는 실패로 반영한다. 작은 문제의 미반환은 최적값 대조 실패다. 기준을 통과하려고 문제를 사후 바꾸지 않았다.

## 지연 관측

사용자 확정 목표는 같은 로컬 합성60문제의 CP-SAT 스냅샷 포함 p95≤1초다. 003에서 194.0ms로 통과했다. 다음 수치는 한 로컬 실행의 관측이며 운영 SLA/실데이터 지연이 아니다. 전체60문제 기준이다. p50은 중앙값, p95는 ceil(0.95×표본 수)의 관측값이다.

| 방식 | 탐색·독립 검증 p50/p95 | 스냅샷 구성+탐색·독립 검증 p50/p95 |
|---|---:|---:|
| CP-SAT | 12.5 / 101.7ms | 24.2 / 194.0ms |
| 최저가 탐욕 | 8.5 / 94.1ms | 18.7 / 183.5ms |
| 성능 탐욕 | 8.5 / 93.5ms | 18.7 / 183.3ms |

정규 해 존재30개에서 CP-SAT의 스냅샷 포함 지연은 다음과 같다.

| 자리당 카드 수 | 문제 수 | p50/p95 |
|---|---:|---:|
| 3 | 12 | 19.8 / 24.9ms |
| 10 | 9 | 64.4 / 71.6ms |
| 30 | 9 | 189.7 / 208.4ms |

원본 가상 자료 생성·기준 스쿼드 검증·전수 탐색 시간은 평가 비용으로 별도 기록하고 요청 경로 시간에 넣지 않았다. Python 프로세스 시작/의존성 import·DB/HTTP 시간도 포함하지 않는다. 목표는 여기 정의한 CP-SAT 요청 경로 p95에만 적용하며 자료 수집/DB/HTTP·운영 SLA나 모든 요청의 최악 지연 상한을 보장하지 않는다.
