# Stage 4-B 합성 build 연결 구현

2026-10-20, [연결 계약](stage-4-b-build-contract.md)의 수동/합성 근거 경로를 구현했다. 실제 LLM·DB/API·새 수집·실데이터 스쿼드 실행은 없다. 1-D·1-F와 의미 추출/평가 미완료를 유지한다.

## 연결 함수

`FRS/core/squad_recommend/build.py`의 `build_squad_request(original, extracted, *, batches, t0, clock, cards, salaries, prices, reinforcements, team_colors)`를 호출한다. 자료를 로드하는 CLI/DB/파일 어댑터는 추가하지 않았다. 모든 자료 iterable·배치·시각·응답 시계는 호출자가 명시한다.

먼저 5조건 정규화를 실행한다. 문제가 하나라도 있으면 정규화 결과만 반환하고 자료 순회·시계 호출·배치/시각 사용·스냅샷·엔진을 시작하지 않는다. 정상일 때만 자료별 BatchSelection을 재검증하고 시간대 있는 datetime t0·정규화 다섯 필드를 SnapshotQuery에 결합한다. 문자열 시각/현재 시각으로 보충하지 않는다.

기존 build_snapshot이 전달한 자료를 한 번씩 검증/복사하며, 기존 solve_squad가 CP-SAT 기본10초/1스레드/시드123과 독립 검증·응답 만료를 수행한다. 슬롯/카드/인물·전원 클럽 자격·합계 제약을 바꾸지 않는다. 이후 무거운 표 생성이나 자료 재조회 없이 정규화·불변 스냅샷·엔진 결과·연결 버전의 SquadBuildResult를 반환한다. 이 래퍼는 필드 재할당을 막으며, 엔진 내부 결과의 계약은 기존 엔진 정의를 따른다.

정규화 실패는 snapshot/engine=None이다. 정상 조건 이후의 배치/시각/자료 형식 오류는 예외로 알리고 사용자 조건 누락이나 해 없음으로 바꾸지 않는다. 응답 시계의 반환값은 기존 엔진 경계에서 검증하며 잘못된 시각을 자동 보정하지 않는다. 빈 후보/해 없음은 제공된 명시 자료 범위의 결과이며 전체 게임에서의 해 없음이 아니다. unknown·internal_error·data_expired 등 엔진 상태를 재시도/다른 방식으로 덮지 않는다.

## 버전과 검증

`build_spec()`은 연결 규칙·정규화/스냅샷/엔진 버전·CP-SAT 설정을 정렬 JSON으로 해시한다. 이번 연결 정책 버전:

`fa18eb9e97dd2d789d9afc4f4e8566852b2e08cc00945638863252eae9feafa0`

새 합성 테스트 **46개**, 전체 pytest **1,097개 통과**. Ruff 린트·포맷, 환경 import, pip check도 통과했다. 필수 명령은 python -m pytest, python -m ruff check ., python -m ruff format --check .이다.

- 세 클럽×세 포메이션의 합성 정상 자료를 실제 CP-SAT에 전달하고 반환 스쿼드를 같은 스냅샷으로 독립 재검증했다.
- 64비트 초과 BP의 1단위 경계·급여 경계/0·없는 강화 관측·혼합 강화5/6·명시 배치 불일치·충돌/미상/만료 제외·빈 후보/해 없음을 확인했다.
- 정규화 누락/미지원/충돌/원문 불일치 시 자료 iterable·시계·스냅샷·엔진 미사용과 사전 배치/시각/자료 계약 위반 시 엔진 미호출을 확인했다.
- 검증기 거부 시 선수 미반환·응답 직전 만료·탐색 전 만료·t0 이전/잘못된 시계 처리·원본 보존·자료 단일 순회·불변 스냅샷·파일/네트워크 부재를 확인했다.
- unknown·internal_error 등 일부 상태 전달은 합성 엔진 대역으로 확인했으며 실제 제한 시간 내 unknown 발생률이나 운영 성능으로 주장하지 않는다.

최신 head의 Linux CI와 실제 병합은 PR에서 별도 확인한다. 이번 기능은 합성 연결이며 새로운 전체 벤치마크/지연 목표 측정이 아니다.

LLM 공급자/모델·비용·실제 의미 추출·표/서술 출력·4-D 의미/E2E 평가·DB/API 연결은 후속이다. 보고되지 않은 미지원 절/부정 해석 오류를 이번 경로가 발견한다고 주장하지 않는다. 공식 팀컬러 발동/보너스·1-D/F 완료·실데이터 서비스 검증이나 새로운 외부 수집 승인은 아니다.
