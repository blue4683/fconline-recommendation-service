## 재현 명령과 보관

저장소 루트의 Python3.11.15 `.venv`에서 실행한다. 아래는 고정 과거 합성 시계를 사용하는 예시이며 현재 서버 자료가 아니다. 이미 사용한 실행 ID 대신 새 ID를 지정한다.

```sh
# 계획만 출력: 자료 생성·엔진·파일 저장 없음
.venv/bin/python -m FRS.evaluation.offline \
  --run-id w6-offline-example-new \
  --observed-at 2026-10-21T00:00:00+00:00

# 같은 명시 계획으로 로컬 합성 검증/보고서 생성
.venv/bin/python -m FRS.evaluation.offline \
  --run-id w6-offline-example-new \
  --observed-at 2026-10-21T00:00:00+00:00 --run
```

기본 경로는 Git 제외 `artifacts/agent-evaluations/<run-id>/`다. 기존 디렉터리는 덮어쓰거나 자동 재개하지 않는다. 계획/전체 근거/자료/결과는 로컬 무기한 보관하며 이 PR에 커밋하지 않는다. `plan.json`, `material.json`, `manifest.json`, `report.md`를 남긴다. 실제 실행이25개 끝나도 실패가 있으면 CLI 종료값1, 모두 계약과 일치하면0이다. 이는 실제 모델의 통과 기준을 새로 확정한 것이 아니다.
