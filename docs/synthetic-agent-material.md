# R1 합성 자료 공급기

2026-10-20. 웹을 제외한 백엔드 재개 W1/R1 구현이다. FRS/agent/material.py에서 명시한 가상 리그를 기존 build/스냅샷 계약에 전달한다. 실데이터 수집/변환·모델 학습/추론·웹/API 연결을 수행하지 않는다.

## 생성 계약

SyntheticLeagueSpec에는 run_id·seed·시간대 있는 observed_at·members_per_family를 모두 명시한다. 현재 합성 생성기 입력은 1~30명/포지션 계열로 제한한다. 이는 생성량 운영 경계이며 실데이터 N=3 정책이나 전 요청의 해 존재 보장이 아니다. 기본값/현재 시각/최신 배치 자동 선택은 없다. 시각은 기존 관측 계약처럼 UTC·밀리초로 정규화한다.

세 정식 클럽 레이블과 MVP 포메이션의 등록 계열 12개를 사용한다. 3명/계열의 검증 fixture는 카드 108개, 5~11강 가격/급여 각 756개, 6~11강 차이 648개, 합성 클럽 자격 108개다. 모든 인물/능력치/OVR/가격/급여/자격은 가상이다.

| 항목 | 명시한 합성 규칙 |
|---|---|
| 인물/카드 | 가상선수 일련번호·가상 시즌 950, 인물 ID는 카드마다 다름 |
| 1강 능력치 | seed가 고정된 로컬 난수로 34개 각각 60~100, 등록 계열 OVR 70~100 |
| 5강 기본 자료 | R0 계산기로 1강+6, 새 버전·배치. 원본 1강은 별도 보존 |
| 6~11강 | B(level)-B(5) 차이·1강 OVR+B(level) 절대값. baseline_card_version은 파생 5강 버전 |
| 가격 | 독립 가상 기본값 10~100 × 1억 BP, 5강 대비 2^(level-5) 배수. 실제 게임 가격 예측 규칙 아님 |
| 급여 | 독립 가상 정수 10~25. 합성 리그에서만 강화 간 동일하도록 생성. 실데이터의 강화 간 불변을 확정한 것 아님 |
| 자격 | 해당 가상 카드의 클럽 레이블 양성. 실제 공식 발동/보너스 규칙 아님 |
| 신체/개인기/발 정보 | 생성하지 않으며 기존 40피처 분류 모델 입력에 사용하지 않음 |
| 기한 | 명시 observed_at에서 기존 D8대로 가격 24시간, 나머지 7일. 로드/요청 시각으로 연장하지 않음 |

생성 규칙 버전·입력/생성 ID·자료별 배치·원본 1강·강화 출처를 canonical payload에 묶는다. seed/시각/생성량/규칙이 바뀌면 배치도 달라져 같은 배치의 값 충돌을 숨기지 않는다. generation_id와 material_id를 기록하며 반복 생성은 같은 입력에서 같은 bytes를 만든다.

## 주입 경계

MaterialProvider.load는 호출자가 명시한 BatchSelection을 요구한다. SyntheticMaterial은 불변 bytes를 보관하고 to_dict/load는 독립 복사본/재검증한 관측만 반환한다. 자료별 배치가 맞지 않거나 합성 출처가 아니면 거부한다. 이는 내부 생성 핸들이며 브라우저/외부 임의 payload를 신뢰할 수 있는 자료로 받는 API가 아니다.

급여 버전은 기존 후보 검색 계약대로 같은 강화 능력치 버전과 연결하고, 가격/자격 버전은 독립이다. 가격/급여/기한/원본 배치를 능력치 규칙으로 추정하지 않는다. 자료 생성과 요청 시각을 분리하며 서버는 생성한 자료의 기한을 확인해야 한다.

## 검증과 남은 작업

신규 합성 테스트 22개: 세 클럽×세 포메이션 실제 CP-SAT/독립 검증, 5/11강 선택, 합계/인물/슬롯·모든 강화 출처 재계산·자료 수·동일 입력 재현/다른 입력 새 배치·독립 복사·틀린 명시 배치·예산 0/인물 부족·24시간 만료·명시 타입/경계·파일/네트워크 부재가 통과했다.

전체 pytest 1,153개·Ruff 린트/포맷·환경 import·pip check가 통과했다. 생성 규칙 버전은 87303f8f5068f98bae12c18902618378b71db7bc057c4f1e7e836953972ffa2a다. 최신 head CI/병합은 실제 완료 후 기록한다. 이 생성기는 임의 예산의 해 존재나 실제 축구/게임 성능을 보장하지 않는다. 기존 D6 벤치마크 생성기와 평가 결과를 수정하지 않았다.

다음 R2에서는 자료 공급기를 주입하고 정규화 오류 시 자료를 읽지 않는 그래프를 연결한다. 아직 API 경로/실제 서버 설정을 확정한 것이 아니며 web-agent.v0는 모의 제안을 유지한다.
