# 프론트엔드 작업 지침

루트 AGENTS.md에 추가하여 frontend/ 작업에 적용한다. [웹 설계도](../docs/web-agent-blueprint.md)와 [공용 기록](../docs/agent-collaboration.md)을 작업 전/재개/PR 전에 읽는다.

- 사용자 확정 스택은 Vue 3 + Vite + TypeScript다. 정확한 런타임/패키지 버전은 호환성을 검증하고 고정하며 미구축 검증을 통과했다고 쓰지 않는다.
- 웹 담당의 수정 범위는 frontend/의 앱·전용 설정/lock·모의 자료·테스트·README와 공용 기록의 자기 WEB-* 항목이다. 이 AGENTS.md 자체는 통합 담당 소유로 읽기 전용이다.
- FRS/ 전체(아직 없는 FRS/agent/ 포함), 기존 tests/·scripts/·Python 의존성·API·Docker/Compose·CI·루트 설정과 설계 문서는 수정하지 않는다. 삭제/이동/심볼릭 링크·설치 스크립트의 간접 변경도 포함한다.
- 백엔드 불일치가 있으면 보호 파일을 고치지 말고 WEB-*로 재현/변경 요청을 기록한다. 통합 담당이 별도 PR에서 수정한다. 의존하지 않는 화면·모의 테스트는 계속할 수 있다.
- 먼저 mock transport로 개발한다. 실제 경로/계약/환경은 통합 담당의 확정 버전·병합 SHA 기록 전까지 추측하지 않는다. live 실패를 mock 성공으로 대체하지 않는다.
- 엔진·정규화·강화 계산·검증기를 브라우저에 복제하지 않는다. 브라우저가 후보/조건/상태/합계를 임의 보정하거나 검증 통과를 만들어 보내지 않는다.
- 금액·급여·ID는 웹 DTO의 정확한 문자열을 유지한다. Number/parseFloat로 변환하지 않는다. 원문·Python 코드포인트 기준 구간을 보존하고 검증 전 LLM 토큰/표를 공개하지 않는다.
- SSE 오류/만료/이전 요청의 늦은 응답을 성공으로 표시하지 않고 자동 재전송하지 않는다. 연결 종료가 서버 계산 취소를 보장한다고 표시하지 않는다.
- 가상 선수/수치만 사용한다. 실제 원본·모델·비밀값을 복사하지 않는다. Vite에서 브라우저에 노출되는 설정에 API 키를 넣지 않는다. 텍스트를 HTML로 실행하지 않는다.
- 별도 작업 디렉터리와 최신 develop 기반 작업 브랜치를 사용한다. 다른 작업자의 파일/브랜치를 임의 변경하지 않는다. 공용 기록도 브랜치 사이에 자동 공유되지 않으므로 읽은 기준 SHA를 남긴다.
- 웹 전용 타입/동작 테스트/빌드와 루트의 Python 필수 검증을 수행한다. 웹 CI는 `.github/workflows/frontend.yml`에서 자동 실행하며 최신 head의 결과를 확인한다. 경로 자동 차단은 아직 없으며 웹 CI를 파일 권한 격리나 실제 브라우저 E2E로 간주하지 않는다.
- PR은 develop 대상이며 통합 담당이 전체 diff·CI·계약을 확인한 뒤 Squash 병합한다. 웹 담당은 병합을 동시에 수행하거나 보호 규칙을 스스로 완화하지 않는다.

이번 파일은 작업 지침만 추가한다. 웹 앱·패키지·API·CI 구현 또는 파일 권한 격리를 제공하지 않는다.
